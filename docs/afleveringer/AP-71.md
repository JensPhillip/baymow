# AP-71 · Mail-svar, første udgave (Apple Mail)

Udført af: Claude Opus 5.5 · Dato: 2026-11-23 · Gren: `main` (brugerens valg)

## Hvad er ændret
- `Features/MailReply/MailReplyText.swift`: `MailThread` (citat-overskrift: "Den … skrev …:", "On … wrote:",
  "Fra:"/"From:", "-----Original"; deling i stikord, signatur og tråd), `MailReplyPrompt` (instruktion, prompt,
  oprydning, [felter]).
- `MailReplyController.swift`: `MailReplySettings` (slået fra, tone, genvej ⌃⌥M), `MailReader` (hele feltet via
  tekstmarkører; stikord via ⇧⌘↑ + ⌘C; afviser, hvis markøren står i tråden), `MailReplyController` (læs → send →
  indsæt i stedet for stikordene, ellers kopiér; Fortryd = ⌘Z).
- `MailReplyPanel.swift`: vinduet. `MailSettingsPage.swift`: siden "Mail".
- `MainWindow.swift`: siden Mail, tre genveje på siden Genvej (ingen dubletter), afsnit på Start, oplæst forklaring.
  `AppShell.swift`: genvej, menupunkt "Svar på mail (⌃⌥M)".
- `CloudSpellingCorrector.send` bruges også af mail-svar (ingen ny netværksfil); tidsgrænse 60 s.
- `SpellingSettings.cloudCorrectorForWriting()`; `CloudSettings` kan vises uden stavehjælpens linje.
- `--mail-test` og `tools/mailtest/`; 10 nye tests (`MailReplyTests`).

## Acceptkriterier
- Mail-testen: **opfyldt** – 18 af 18 (6 tråde × 3 kørsler), ingen opdigtede tal, ordren i tråden ikke fulgt.
- Tests af opdeling, instruktion og oprydning: **opfyldt**.
- Brugeren har prøvet i Apple Mail: **afventer**.
