# AP-75 · Tekst fra skærmen (idé I4)

Udført af: Claude Opus 5.5 · Dato: 2026-11-24 · Gren: `main` (brugerens valg)

## Hvad er ændret
- `Features/ScreenText/ScreenTextRecognizer.swift` (ny): `ScreenTextRecognizer` (Vision, `da-DK` + `en-US`, nøjagtig;
  `layout` sætter linjer sammen oppefra og ned, venstre mod højre, afsnit ved store mellemrum, ord med bindestreg samles),
  `DanishLetterFix` (æ/ø/å-forvekslinger rettes kun ved ét entydigt bud fra den danske stavekontrol), `ScreenCapture`
  (tilladelse og billede af et område med ScreenCaptureKit, macOS 15.2+).
- `ScreenTextController.swift` (ny): `ScreenTextSettings` (fra, ⌃⌥T), `ScreenTextController` (tilladelse → firkant →
  billede → tekst → oplæsning; små beskeder: ingen tekst, mangler lov, kræver macOS 15.2), `SelectionOverlay` (halvmørkt
  lag på alle skærme, Esc fortryder, fokus tilbage til programmet bagefter).
- `AppShell.swift`: genvej, menupunkt "Læs tekst fra skærmen", oplæsning via `ReadingSessionManager.start` (kernen uændret).
- `MainWindow.swift`: Oplæsning (kontakt, genvej, tilladelse), Start (afsnit), Genveje (femte genvej), oplæst forklaring.
- `--ocr-test`, `tools/skaermtekst/`; 5 nye tests.

## Acceptkriterier
- OCR-målingen: **opfyldt** – 0 % tegnfejl i skarp, lille uden Retina, med fødder, lysegrå og mørk tilstand; 1,1 % på
  "indscannet" (1,9 % før æ/ø/å-rettelsen). Ca. 0,1–0,2 s pr. afsnit.
- Tests: **opfyldt** (183 i alt).
- Brugeren har prøvet: **afventer**.

## Kontrol, jeg selv har kørt
- `Baymow --ocr-test tools/skaermtekst/tekster.txt …`.
- `Baymow --render-ui`: Oplæsning med den nye kontakt.
- `./Scripts/check.sh`: ALT GRØNT; netværk kun i godkendte filer (tekst fra skærmen bruger intet netværk).

## Ikke kontrolleret
- Firkanten på rigtige skærme (også to skærme), tilladelsen Skærmoptagelse og billedet af det rigtige område.
- Tekst i flere kolonner (læses linje for linje på tværs).
