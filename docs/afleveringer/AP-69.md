# AP-69 · Skrifttype og størrelse i Word

Udført af: Claude Opus 5.5 · Dato: 2026-11-23 · Gren: `main` (brugerens valg)

## Hvad er ændret
- `RTFText.swift` (ny): læser de synlige tegn i RTF (springer skrifttabel, farver, billeder, `\*`-grupper og
  punktformens `\listtext` over; forstår `\'xx`, `\uN` med reserve-tegn, `\par`, `\tab`). Rettelser skiftes ind tegn for
  tegn; formateringskoder imellem bliver stående. Ny tekst skrives med `{\uc1\uN?}` for specialtegn.
- `RichReplacement.swift`: `edits(_:in:)` finder rettelserne (fælles for RTF og HTML). `formatted(from:segments:)`
  foretrækker programmets egen RTF; ellers HTML. Kun det format, programmet gav, sættes ind (plus ren tekst).
- `SpellingController.swift`: bruger det nye.
- 5 nye tests med RTF som fra Word.

## Acceptkriterier
- Tests med Word-lignende RTF: **opfyldt** (Aptos og `\fs24` urørt, fed bevaret, æøå, komma tilføjet, punktform,
  RTF'en kan læses af macOS bagefter).
- Brugeren har prøvet i Word: **afventer**.

## Kontrol, jeg selv har kørt
